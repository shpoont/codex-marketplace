# Changelog

## Purpose

Record changes that affect Harbor users and any required update actions.

## Rationale

Users should understand evaluation capabilities, prerequisites and safe use
from the installed package.

## 0.1.0 — 2026-10-28

### Added

- Harbor agent-evaluation methodology, including realistic cases, verifier
  calibration, isolation, installed-version checks and honest result reporting.
- Focused investigation guidance with incident reproduction, evidence reuse,
  cumulative effort limits and explicit stopping conditions.
- Plugin installation, update, removal and support documentation.
