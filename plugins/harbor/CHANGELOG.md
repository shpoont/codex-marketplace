# Changelog

## Purpose

Record changes that affect Harbor users and any required update actions.

## Rationale

Users should understand evaluation capabilities, prerequisites and safe use
from the installed package.

## 0.2.0 — 2026-10-28

### Added

- Six officially sourced Harbor skills with `official-` slugs and Official
  display names, preserving their upstream guides and supporting files.
- Shared safeguards for installed versions, bounded execution, isolated grading,
  reviewed external writes and ambiguous-result reconciliation.
- Optional parity PR helper, with explicit external Python dependency setup.
  Installation and ordinary skill loading create no PRs or uploads.
- Pinned upstream revision, per-file hashes and Apache-2.0 notices. Our existing
  methodology skill and its six files remain unchanged.

### Changed

- Use Harbor Framework's official logo, preserved without modification,
  with pinned provenance and the upstream Apache-2.0 license.

## 0.1.0 — 2026-10-28

### Added

- Harbor agent-evaluation methodology, including realistic cases, verifier
  calibration, isolation, installed-version checks and honest result reporting.
- Focused investigation guidance with incident reproduction, evidence reuse,
  cumulative effort limits and explicit stopping conditions.
- Plugin installation, update, removal and support documentation.
